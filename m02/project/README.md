# Міні-проєкт модуля 2: калькулятор рахунку в кафе

Компанія друзів поїла в кафе. Треба порахувати чайові й скільки платить кожен.
Напиши програму `bill.py` у цій папці.

## Що має робити програма (обов’язково)
1. Питає суму рахунку в гривнях (може бути з копійками: `1234.50`).
2. Питає відсоток чайових (наприклад, `10`).
3. Питає кількість людей.
4. Виводить красивий чек з вирівняними колонками:

```text
==============================
        РАХУНОК У КАФЕ
==============================
Сума рахунку           1234.50
Чайові (10%)            123.45
------------------------------
Разом                  1357.95
Людей                        4
З кожного               339.49
==============================
```

## Технічні вимоги
- Лише те, що є в модулях 1–2: змінні, числа, `input`, `int`/`float`, f-рядки з вирівнюванням.
- Рамки з `=` і `-` роби множенням рядка (`"=" * 30`), а не вручну.
- Змінні з зрозумілими іменами (`tip_percent`, а не `x`).

## Бонус (за бажанням)
- Округли «з кожного» **вгору** до цілих гривень, щоб точно вистачило (`import math`, `math.ceil`), і покажи, скільки залишиться «на здачу».
- Виведи також, скільки це в доларах за курсом, який введе користувач.

## Як здати
1. Запусти програму з кількома різними даними й переконайся, що числа правильні (перевір на калькуляторі).
2. Зроби коміт у свій репозиторій `python-course`: `git add . && git commit -m "Add bill calculator"`.
3. Встав код у поле «Перевірка тімлідом» на сторінці міні-проєкту на сайті й отримай рев’ю від Claude.
