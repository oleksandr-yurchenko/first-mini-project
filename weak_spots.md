# Мої слабкі місця

Сюди записується все, на чому я застрягав за весь час навчання. Claude бере ці теми
для задач на повторення: щодня одна з трьох задач — звідси. Коли тема більше не
викликає проблем, познач її ✓ (не видаляй).

## Загальні звички (стосуються всього)

- [ ] **Розуміти ≠ вміти написати.** Читаючи, все зрозуміло; з порожнього файлу — важко. Лікується лише розв’язуванням самому.
- [ ] **Не покладатися на підказки редактора.** Copilot у VS Code дописував код замість мене (задача з паліндромом). Під час навчання вимкнено.
- [ ] **Розбивати задачу на кроки.** Кожен рядок умови — окремий маленький крок, один рядок коду.
- [ ] **`print` після кожного кроку.** Дивитися, що лежить у змінній, а не вгадувати.
- [ ] **Читати помилку знизу.** Останній рядок каже, що не так (`IndexError`, `AttributeError`, `SyntaxError`, `ValueError`).
- [ ] **Назва змінної з умови.** Перевірка шукає саме ту назву, що в умові (`is_palindrome`, `clean`, а не `palindrom`, `full`).

## Етап 0 · Терміни й інструменти (вересень 2026)

- [ ] **Python ≠ термінал.** Термінал (PowerShell, `PS C:\...>`) — місце для команд. Python — мова; REPL (`>>>`) — це Python, запущений у терміналі командою `python`.
- [ ] **Як запустити файл.** У терміналі, в папці з файлом: `python назва.py`. У VS Code — кнопка ▶.
- [ ] **Термінал vs REPL.** У `PS ...>` пишуть команди (`python file.py`, `cd`, `git`); у `>>>` — код Python. Вийти з REPL: `exit()`.
- [ ] **Що таке Git.** Не «підключення», а система збереження версій коду (знімків/комітів). GitHub — сайт, де ці версії зберігаються онлайн.

## Модуль 2 · Рядки (18–19.10.2026)

- [ ] **Індекс списку і індекс рядка.** `parts[1]` бере слово зі списку, `parts[1][0]` — першу літеру цього слова.
- [ ] **Конвеєр змін.** Кожен крок бере результат попереднього: `clean = clean.strip()`, а не знову `raw.strip()`.
- [ ] **Дужки після методу.** `raw.title()` — метод, дужки потрібні. `phrase` — змінна, дужок не треба.
- [ ] **Що пишуть у дужках `split`.** Символ, по якому різати: `split(",")`. Порожні дужки `split()` ріжуть по пробілах, скільки б їх не було. `split(" ")` — це один пробіл, зайві пробіли лишаться.
- [ ] **Тип змінюється.** Після `split()` у змінній список, і методи рядка (`title`, `strip`) з ним не працюють → `AttributeError: 'list' object has no attribute ...`.
- [ ] **`split` і `join` — пара.** `split` розбирає рядок на список, `join` збирає назад. `join` пишеться навпаки: спершу роздільник, потім список — `" ".join(words)`.
- [ ] **Зріз.** Квадратні дужки одразу після змінної, без круглих: `s[::-1]`, `s[1:4]`. Кінець зрізу не включається.
- [ ] **Видалити символ.** `replace(" ", "")` — замінити на порожній рядок.
- [ ] **Склеювання через `+`.** Пробіли й крапки самі не з’являються — їх доклеюють: `a + " " + b + "."`.

## Модуль 2 · Введення й виведення (27.10.2026)

- [ ] **Навіщо `int()` / `float()` навколо `input()`.** `input()` завжди дає текст. Щоб рахувати, текст треба перетворити на число: інакше `"5" + "5"` → `"55"`, а `"20" + 1` → `TypeError`. `int` — для цілих, `float` — для дробових (`int("72.5")` → `ValueError`).
