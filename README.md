# Калькулятор рахунку в кафе

Мій перший міні-проєкт на Python (курс «Python Шлях», модуль 2).

Програма питає суму рахунку, відсоток чайових і кількість людей,
а потім друкує акуратний чек: суму, чайові, разом і скільки платить кожен.

## Як запустити
```
python main.py
```

## Приклад
```
==============================
        РАХУНОК У КАФЕ
==============================
Сума рахунку           1250.00
Чайові   10%            125.00
------------------------------
Разом                  1375.00
Людей                        4
З кожного               343.75
==============================
```

## Що використано
- `input()` і перетворення типів (`int`, `float`, `Decimal`)
- арифметика й відсотки
- f-рядки з вирівнюванням (`:>18.2f`)
