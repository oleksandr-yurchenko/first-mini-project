# Файли задач з автоперевіркою

Тут лежать задачі до уроків. Кожен файл — одна задача: умова вгорі, місце для твого коду
посередині, автоперевірка внизу.

## Як працювати
1. У VS Code: **File → Open Folder** → вибери папку `practice` (цю). Зліва будуть усі модулі.
2. Розгорни потрібну папку: `m00` (етап 0), `m01` (модуль 1), `m02` (модуль 2), `daily` (щоденні задачі).
3. Відкрий файл задачі, прочитай умову, напиши код між рядками
   `↓↓↓ ТВІЙ КОД НИЖЧЕ ↓↓↓` і `↑↑↑ ТВІЙ КОД ВИЩЕ ↑↑↑`.
4. Запусти: кнопка **▶** угорі праворуч або в терміналі `python назва_файлу.py`.
5. Унизу з’явиться результат:
   - `✓ Усе правильно!` — задачу розв’язано, відміть її на сайті;
   - `✗ ...` — що саме не так, і підказка. Виправ і запусти знову.

## Що де лежить
| Папка | Що там |
|---|---|
| `m00` | етап 0: перевірка налаштування комп’ютера (`m00_check_setup.py`) і перші програми |
| `m01` | модуль 1: ділення, `len`, `type`, візитка; перевірки `.venv` і Git |
| `m02` | модуль 2: змінні, числа, рядки, введення й виведення + міні-проєкт |
| `daily` | щоденні задачі: щодня о 20:00 нова папка з датою |
| `weak_spots.md` | твої слабкі місця — з них беруться задачі на повторення |

Файли з назвою `..._check_...py` нічого не просять писати: просто запусти їх, і вони перевірять,
чи правильно налаштовано комп’ютер або проєкт.

## Правила
- Файл `_check.py` не змінюй: це перевірялка.
- Блок «автоперевірка, не змінюй» внизу файлу теж не чіпай.
- Спершу розв’язуй сам. Підказка в ✗ з’являється лише після спроби.
- Застряг на 20+ хвилин — встав свій код у чат з Claude і попроси підказку (не готовий розв’язок).

## Чому так
Саме так перевіряють код на роботі: є автоматичні тести, ти пишеш код, поки вони не стануть
зеленими. В етапі 2 ці перевірки перетворяться на справжній `pytest`.
